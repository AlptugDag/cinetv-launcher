# Code of conduct

CineTV is a small project built for people who love films. Keep it that way:

- Be kind and specific. Critique code and ideas, never people.
- Help newcomers. Many people arrive here with their first `adb` command.
- No harassment, discrimination, spam, or sharing someone else's work as your own.
- Never post anyone's API keys, pairing codes, IP addresses or personal data, including your own.
- No links to pirated content. CineTV opens the apps you already use; it does not host or index media.

Maintainers may edit, hide or remove content and block accounts that break these rules. Report
problems through a GitHub issue, or privately through the repository's security advisory form
(**Security → Report a vulnerability**) when the matter is sensitive.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
